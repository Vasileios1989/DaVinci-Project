# DaVinci Fitness — μηχανή υπολογισμού

Υλοποίηση των εγκεκριμένων εγγράφων του project (Στοιχεία 01–46), ένα στοιχείο τη φορά.

- `data/` — όρια, πίνακες και μηνύματα κάθε στοιχείου (JSON). Κάθε τιμή έχει πηγή και επίπεδο επαλήθευσης ή σήμανση «σύμβαση συστήματος».
- `src/davinci/` — ένα module ανά στοιχείο· `registry.py` είναι το μόνο σημείο σύνδεσης.
- `tools/` — βοηθητικά σενάρια (π.χ. μετατροπή των δεδομένων ΠΟΥ).
- `tests/` — τα τεστ ελέγχουν ότι ο κώδικας κάνει ό,τι γράφει το έγγραφο. Δεν ελέγχουν αν το έγγραφο είναι επιστημονικά σωστό.

Εκτέλεση τεστ: `python -m pytest`

Κατάσταση και εκκρεμότητες: `NOTES.md`.

Εφαρμογή: `streamlit run streamlit_app.py` (στο Streamlit Community Cloud: κύριο αρχείο `streamlit_app.py`). Η λογική της είναι στο `src/davinci/app_logic.py`.
